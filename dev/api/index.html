InfiniteTEBD.Blockade — Type
Blockade(; occupied=2)

The nearest-neighbour blockade projector P = ∏_j (1 − n_j n_{j+1}) on a chain, with n = |occupied⟩⟨occupied| (basis index occupied, 2 = |1⟩ for spin-½). It forbids two adjacent sites from both being in state occupied; any local dimension is allowed.

constraint_leakage computes the blockade probability from a positive transfer on two environments labelled by the previous site's occupation. This sum of non-negative terms retains the relative accuracy of small weights.

iMPO(b, n; d=2) gives the same projector as a general layer MPO, for comparison or for code that needs an iMPO.

InfiniteTEBD.CanonicalFormError — Type
CanonicalFormError

Thrown when the QR/LQ iteration that restores the canonical form after an MPO application (or for a projected state) does not converge, typically for states with a very long correlation length. It signals a solver failure, not a property of the state.

InfiniteTEBD.ControlledGate — Type
ControlledGate(left::Diagonal, U::AbstractMatrix, right::Diagonal)

Prepare a three-site gate which acts with U on the central site when both outer sites are in the diagonal projectors left and right. Elsewhere the gate is the identity. The projectors have entries 0 or 1. Use the prepared gate with applygate! or an evolve! gate list.

InfiniteTEBD.EndpointGate — Method
EndpointGate(A, B, scale; op_rtol=nothing)

Prepare exp(scale * kron(A, B)) for Hermitian local operators A and B, directly from their local eigensystems. This uses a phase table of size size(A, 1) × size(B, 1) in place of a fused two-site exponential. op_rtol controls the relative cutoff in the operator Schmidt decomposition. Use scale=-im*dt for real-time evolution.

InfiniteTEBD.MPOAnnihilationError — Type
MPOAnnihilationError

Thrown by apply! (and the MPO evolve!) when the MPO maps the state to zero, i.e. to a norm per cell at the roundoff level of the contraction. The state passed to apply! is left unchanged. A search can catch this type to tell "candidate excluded by a projector" apart from a solver failure.

InfiniteTEBD.iMPO — Type
iMPO{T}

Infinite matrix-product operator with a periodic unit cell of n sites.

Fields:

  • W::Vector{Array{T,4}} One tensor per unit-cell site, indexed W[i][l, o, s, r]: left bond l, output (bra) physical index o, input (ket) physical index s, right bond r. Shape (Dl, d_out, d_in, Dr). The bond to the right of site i must match the bond to the left of site i + 1, with periodic wraparound.
  • n::Int Unit-cell length.

Indexing W[i] returns the tensor of site mod1(i, n). The operator acts on an iMPS whose unit cell is a multiple of n; see apply!.

Construct from a list of tensors with iMPO(Ws), or from commuting local gates with layer_mpo and trotter_mpos. A * B is the operator product (B acts first); see mpo_multiply.

Example:

X = ComplexF64[0 1; 1 0]
W = iMPO([reshape(X, 1, 2, 2, 1)])   # the product operator ⊗_j X_j
bonddims(W)                          # [1]

InfiniteTEBD.iMPS — Type
iMPS

Infinite matrix-product state with a finite unit cell.

Type parameters:

  • ΓT: storage type of each local tensor (e.g. Array{ComplexF64, 3} for the dense backend; TensorMap for the symmetric backend supplied by an extension).
  • λT: storage type of each Schmidt spectrum (e.g. Vector{Float64} for the dense backend; DiagonalTensorMap for the symmetric backend).

For the dense default, see the type alias DenseIMPS.

Fields:

  • Γ::Vector{ΓT} Stored local tensors for one periodic unit cell. In this package these are the right-canonical tensors B_i = Γ_i λ_i, not the bare Vidal tensors usually denoted Γ_i in the iTEBD literature.
  • λ::Vector{λT} Schmidt spectra across the bonds of the unit cell. λ[i] is the Schmidt spectrum on the bond to the right of site i, with periodic wraparound.
  • n::Int Number of sites in the periodic unit cell.

Convention:

  • ψ.Γ[i] stores the right-canonical tensor B_i.
  • ψ[i] returns the bare Vidal tensor Γ_i together with λ[i].

After canonicalization, the entanglement structure of the state is stored explicitly in λ, while the local tensors in Γ are right-canonical.

Notes:

  • The package is written for the injective setting used by standard iTEBD workflows.
  • Many internal contractions operate directly on the stored tensors B_i rather than reconstructing bare Vidal tensors first.

InfiniteTEBD.iMPS — Method
iMPS(T, Γs; renormalize=true)

Construct an iMPS from a list of local tensors with element type T.

Parameters:

  • T Element type used for the stored tensors.
  • Γs Vector of local three-leg tensors, one per site in the unit cell. These are interpreted as raw input tensors; they do not need to already satisfy the package's canonical convention.

Keyword arguments:

  • renormalize=true If true, the constructed state is immediately brought to the package's Schmidt-canonical form with canonical!. If false, the tensors are stored as given and the Schmidt vectors are initialized as trivial all-ones placeholders.

Returns:

  • A new iMPS with unit-cell length length(Γs).

Notes:

  • For normal user-facing construction, leaving renormalize=true is strongly recommended.
  • When renormalize=false, the resulting object may not yet satisfy the stored right-canonical convention expected by many higher-level routines.

Example:

Γs = [rand(ComplexF64, 2, 2, 2), rand(ComplexF64, 2, 2, 2)]

InfiniteTEBD.apply! — Method
apply!(ψ, W::iMPO; maxdim=MAXDIM, cutoff=SVDTOL, truncerr=0.0, renormalize=true, recanonicalize=true, return_stats=false, structured=true, orth_tol=nothing)

Apply the infinite MPO W to ψ in place and truncate.

The cell length of ψ must be a multiple of W.n. Each stored tensor B_i = Γ_i λ_i is contracted with W[i] (the bond dimensions multiply), after which the state is brought to exact canonical form and every bond keeps its own largest Schmidt values, as in truncate!: at most maxdim, with discarded weight at most truncerr when truncerr > 0, and none below cutoff. orth_tol controls the orthonormalization sweeps as in truncate!.

W need not be unitary: imaginary-time layers and projectors work. With renormalize=true (the default) the result is normalized.

Failure handling: the update is computed on new arrays and committed only on success, so if apply! throws, ψ is unchanged. An MPO that annihilates the state throws MPOAnnihilationError: W·ψ is treated as zero when its norm per cell, relative to the input's, is at the roundoff level of the contraction (≈ 10⁴ ε ∏ᵢ ‖Wᵢ‖).

This is the procedure of Orús and Vidal (PRB 78, 155117, Sec. III): contract, orthonormalize, truncate all bonds at once. The orthonormalization is the single-layer QR iteration of Vanderstraeten, Haegeman and Verstraete (SciPost Phys. Lect. Notes 7, Sec. 2.3), which resolves Schmidt values to machine precision rather than its square root. Exact null directions of the enlarged bond are removed. With recanonicalize=false a truncated state is not regauged: the tensors are not in canonical form and the stored λ are only the sliced spectra, so Schmidt-gauge observables (expect, ent_S) are not reliable until the next apply!, truncate! or canonical!. With renormalize=true the state is still normalized per cell (the transfer-matrix norm is divided out). evolve! skips that normalization in all but its last application, since the next application canonicalizes anyway.

Structured update: if W carries a controlled-center structure (see layer_mpo), structured=true, the state is a dense complex two-site cell and renormalize=true, the update is computed sector by sector over the control occupations instead of from the enlarged MPO×MPS. It is the same state, truncated by the same code; it falls back to the generic update if its iteration does not converge or anything fails numerically. stats.path reports which update ran (:controlled or :generic).

Returns ψ, or (ψ, stats) with return_stats=true. stats matches the style of evolve!: path, bond_stats (one BondStat per bond), max_discarded_weight (fraction of the squared Schmidt weight discarded, maximized over bonds), kept_dims and num_saturated (bonds where maxdim removed Schmidt values at or above the truncation floor max(cutoff, 1e-14); values the cutoff removes anyway are not counted).

Example:

X = [0 1; 1 0]; P = [1 0; 0 0]
W = layer_mpo([(exp(-0.1im * kron(P, X, P)), 2, 4)], 2)
psi = product_iMPS(ComplexF64, [[1, 0], [1, 0]])
apply!(psi, W; maxdim=16)

InfiniteTEBD.apply_chain_transfer — Method
apply_chain_transfer(T1s, T2s, ρ; dir=:r)
apply_chain_transfer(ψ1, ψ2, ρ; dir=:r)
apply_chain_transfer(ψ, ρ; dir=:r)

Apply the n-site unit-cell mixed transfer E_cell = E_1 · E_2 · … · E_n to a matrix ρ via a site-by-site sweep, without materializing any χ²×χ² intermediate.

T1s supplies the conjugated tensors and T2s supplies the unconjugated tensors. The tensor lists must have equal nonzero length and matching physical dimensions at every site. The dense iMPS methods use the stored unit-cell tensors, with apply_chain_transfer(ψ, ρ) giving the self transfer. For these periodic states, the input and result of either sweep have shape (χ₂, χ₁), where χᵢ is the wraparound bond dimension of ψᵢ.

Cost is O(n·d·χ³) per call versus O(n·χ⁶) for the dense product, with identical numerical result up to roundoff. For dir=:r the sweep applies E_n first, then E_{n-1}, …, then E_1, matching the matrix-product ordering returned by gtrm. dir=:l sweeps from the first site to the last and applies the transpose of that dense matrix in vectorized form. Both sweeps leave ρ and the tensors intact and return a new matrix.

InfiniteTEBD.apply_endpoint_gate! — Method
apply_endpoint_gate!(ψ, G, i, j; method=:mpo, op_rtol=nothing, kwargs...)

Compatibility entry point for a two-site matrix in the usual kron(left, right) convention acting at the ends of the forward interval from i to j. For prepared gates use applygate!.

method=:mpo factors the matrix using the relative operator Schmidt cutoff op_rtol. method=:swap uses adjacent ordinary swaps, requires equal physical dimensions along the interval, and can truncate during routing. Both methods accept the usual state truncation and gauge options. With return_stats=true, report the local cuts in update order.

InfiniteTEBD.apply_transfer — Method
apply_transfer(T1, T2, ρ; dir=:r)

Apply the single-site mixed transfer map E(T1, T2) to a matrix ρ without materializing the dense transfer matrix M produced by gtrm(T1, T2).

With T1 of shape (χL1, d, χR1) and T2 of shape (χL2, d, χR2):

  • dir=:r takes ρ of shape (χR2, χR1) to a matrix of shape (χL2, χL1):

    ρ'[a, b] = ∑_{a',b',s} T2[a, s, a'] * ρ[a', b'] * conj(T1[b, s, b'])

  • dir=:l takes ρ of shape (χL2, χL1) to a matrix of shape (χR2, χR1) via the left sweep, with vec(result) = transpose(M) * vec(ρ). This preserves the bilinear pairing with the right sweep, including for complex mixed transfers.

Each call costs O(d·χ³) and is the matrix-free building block underlying the fast inner_product Krylov path.

InfiniteTEBD.applygate! — Method
applygate!(ψ, gate::Union{EndpointGate,ControlledGate}, i, j; kwargs...)

Apply a prepared gate on the forward periodic interval from i to j. The interval must fit in one unit cell. EndpointGate acts on its two ends. ControlledGate requires a three-site interval.

The usual truncation controls apply to the state. Set the operator Schmidt cutoff op_rtol when constructing an EndpointGate. return_stats=true reports local bond cuts in sweep order. recanonicalize=true runs canonical! after an endpoint update or after a controlled update that crosses the cell seam. This can truncate bonds outside the interval and is excluded from the local cut statistics. Use gauge=:auto (or :gram or :qr) for fixed-dimension gauge restoration.

InfiniteTEBD.applygate! — Method
applygate!(ψ, G, i, j; maxdim=MAXDIM, mindim=1, truncerr=0.0, svd_min=SVDTOL, renormalize=true, recanonicalize=false, gauge=nothing, return_stats=false)

Apply a local gate G in place to the contiguous region from site i to site j of the periodic unit cell.

Parameters:

  • ψ State to update in place.
  • G Dense local operator. Its dimension must match the total physical dimension of the block from site i to site j.
  • i, j Start and end sites of the support inside the unit cell. If j < i, the support is interpreted with periodic wraparound.

Keyword arguments:

  • maxdim=MAXDIM Hard cap on the retained bond dimension during the decomposition of the updated block.
  • mindim=1 Minimum retained bond dimension on each updated internal bond.
  • truncerr=0.0 Target discarded weight used to choose the smallest admissible kept bond dimension on each updated internal bond. Set truncerr = 0 for fixed-cap evolution.
  • svd_min=SVDTOL Optional absolute singular-value floor applied after the discarded-weight target is evaluated.
  • renormalize=true Whether to renormalize the retained Schmidt values.
  • recanonicalize=false After a wrap-around gate (j < i), whether to re-canonicalise the unit cell. The SVD chain inside tensor_applygate! keeps the affected block right-canonical locally, and for unitary gates with no truncation it preserves the global canonical form exactly — so the default false skips the O(χ⁶) canonical! call, which is the right choice for real-time unitary evolution. For non-unitary gates (e.g. imaginary-time exp(-dt·h)), or whenever truncation discards weight, the wraparound seam drifts from canonical form; pass recanonicalize=true so observables and downstream truncations stay accurate. Note: over long unitary evolutions the Vidal-gauge division by small Schmidt values accumulates drift too, so re-canonicalise periodically if you need high accuracy.
  • gauge=nothing Request a fixed-bond-dimension gauge checkpoint after this gate with :gram, :qr, or :auto. Requires renormalize=true and recanonicalize=false. A failed gauge checkpoint leaves the input intact.
  • return_stats=false If true, also return per-bond truncation diagnostics for this gate update.

Returns:

  • ψ when return_stats = false.
  • (ψ, stats) when return_stats = true, where stats.bond_stats contains one entry per updated internal bond.

Notes:

  • For a one-site update with i == j, the operator is applied directly to the stored local tensor without a block decomposition.
  • For multi-site updates, this routine works directly with the stored right-canonical tensors ψ.Γ.
  • Site indices are interpreted periodically through the finite unit cell.
  • Multi-site gates follow the documented kron convention: the leftmost site of the support corresponds to the leftmost kron factor, so kron(A, B) applied to (i, i+1) acts A on site i and B on site i+1. The conversion to the internal fused-leg layout happens inside this routine.
  • The gate's element type must be representable in the state's element type: applying a complex gate to a real-eltype state throws an ArgumentError (construct the state with ComplexF64, or convert it with mps_promote_type).

Example:

psi = product_iMPS(ComplexF64, [[1, 0], [0, 1]])
X = [0 1; 1 0]
applygate!(psi, kron(X, X), 1, 2; maxdim=4)

InfiniteTEBD.canonical! — Method
canonical!(
    ψ;
    maxdim=MAXDIM,
    cutoff=SVDTOL,
    renormalize=true,
    noninjective=:warn,
    symmetry_break=:none,
)

Bring ψ to Schmidt-canonical form in place.

This is the standard normalization step used throughout the package after applying gates or rebuilding an iMPS from raw tensors.

Convention note:

  • The package stores right-canonical tensors B_i = Γ_i λ_i.
  • The Schmidt spectrum on bond i is still kept separately as λ[i].
  • Calling ψ[i] returns the bare Vidal tensor Γ_i together with λ[i] by dividing out the absorbed right Schmidt values.

This routine uses the standard injective canonicalization path, with a conservative warning/sector-selection policy for likely non-injective inputs.

Parameters:

  • ψ State to canonicalize in place.

Keyword arguments:

  • maxdim=MAXDIM Maximum number of Schmidt values retained on each bond during the internal SVD step. This acts as a hard bond-dimension cap.
  • cutoff=SVDTOL Singular values smaller than this threshold are discarded during canonicalization.
  • renormalize=true If true, renormalize the retained Schmidt values after truncation. For a multi-site cell, renormalize=false keeps the scale of the retained state. With no truncation this is the original norm per cell. The one-site path includes a final normalization.
  • noninjective=:warn Policy for likely non-injective or degenerate transfer spectra. Supported values are :warn, :error, and :ignore.
  • symmetry_break=:none Do not run the explicit deterministic sector-selection heuristic for likely non-injective tensors. Use :auto to enable that heuristic for simple block-diagonal/GHZ-like tensors.

Returns:

  • The same object ψ, mutated in place.

Notes:

  • The stored tensors after this call satisfy the package convention ψ.Γ[i] = B_i = Γ_i λ_i.
  • If you canonicalize with a small maxdim or a large cutoff, the resulting state is the truncated state.
  • Dense cells with any fused prefix above 1 MiB, or whose physical dimensions differ, use sitewise transfer contractions and a streaming split with the same seam and left-to-right order of SVD cuts. The streaming degeneracy diagnostic uses the transfer spectrum on small virtual bonds and a diagonal-sector heuristic on larger bonds.
  • The bare Vidal tensors can be recovered afterwards with ψ[i].

Example:

psi = rand_iMPS(ComplexF64, 1, 2, 4)
canonical!(psi; maxdim=4, cutoff=1e-12, renormalize=true)
Gamma1, lambda1 = psi[1]

InfiniteTEBD.check_commuting — Method
check_commuting(layer; n=nothing, atol=1e-12, d=nothing)

Check numerically that the overlapping gates of layer commute, and throw an ArgumentError naming the first offending pair otherwise. Returns true.

layer is a list of (G, i, j) tuples. Supports follow the convention of layer_mpo: i ≤ j are chain sites, possibly more than one cell. With n given, the layer is treated as periodic with period n, and every translate of every gate is tested against every overlapping translate (including a gate against its own translates). Without n, only the listed gates are compared, at the listed positions.

The test is ‖AB − BA‖ ≤ atol · ‖A‖ · ‖B‖ (Frobenius norms) on the union of the two supports. Gates that do not overlap always commute.

Example:

n = [0 0; 0 1]; X = [0 1; 1 0]
check_commuting([(kron(n, X), 1, 2), (kron(n, X), 2, 3)])  # throws: X and n meet on site 2

InfiniteTEBD.compress_mpo — Method
compress_mpo(W; cutoff=1e-14, orth_tol=nothing)

Remove redundant bond dimension from an iMPO.

W is treated as an iMPS in operator space (physical leg d_out · d_in) and brought to canonical form; operator Schmidt values below cutoff (relative to a unit Hilbert-Schmidt norm per cell) are dropped. The complex scale per cell is restored afterwards, so the result represents the same operator, not just the same operator up to normalization. If no bond shrinks, W itself is returned unchanged.

Use orth_tol to set the canonicalization tolerance as in truncate!. This is meant for exact (lossless up to cutoff) compression, e.g. after a product of MPOs. It assumes the operator, viewed as a state, is injective.

InfiniteTEBD.constraint_leakage — Method
constraint_leakage(ψ, P::iMPO)

Per-site leakage of ψ out of the subspace of the projector MPO P: −log F_P with F_P = |⟨ψ|φ⟩|^(1/n) the per-site fidelity between ψ and its normalized projection φ = P|ψ⟩/‖P|ψ⟩‖. For a projector this is −log(⟨ψ|P|ψ⟩) / (2n) per cell of n sites, the same normalization as the ScarFinder loss, so the two can be compared directly. Returns Inf if P annihilates ψ. ψ is not modified.

P must be a projector (e.g. the blockade ∏(1 − n_j n_{j+1}) built with layer_mpo); the formula is not meaningful for other operators. The projection is computed without truncation. For the nearest-neighbour blockade prefer constraint_leakage(ψ, Blockade()), which needs no projection and keeps small weights accurate; see Blockade.

InfiniteTEBD.energy_density — Method
energy_density(ψ, terms; n=ψ.n)

Energy per site of the site-dependent local terms terms, a list of (h, i, j) that is repeated with period n (the support convention of layer_mpo: i ≤ j may span more than the cell).

ψ.n must be a multiple of n. The result is (1 / ψ.n) · ∑_{translates within ψ's cell} ∑_terms ⟨h⟩; for a two-site PXP cell with terms = [(h_A, 2, 4), (h_B, 1, 3)] this is (⟨h_A⟩ + ⟨h_B⟩) / 2. ψ must be in canonical form (as returned by canonical!, apply!, truncate!, …).

This complements energy_density(ψ, h), which averages one density h over all sites.

InfiniteTEBD.energy_fix! — Method
energy_fix!(ψ, terms_or_layers, χ; target, tol=1e-6, alpha=0.1, maxstep=50, n=ψ.n, cutoff=SVDTOL, structured=true, orth_tol=nothing)

Move the energy per site of ψ toward target with short imaginary-time steps built as layer MPOs from site-dependent terms.

terms_or_layers is either a list of commuting layers (as for trotter_mpos) or a flat list of terms (h, i, j), which is split greedily into layers that satisfy the layer_mpo precondition. The terms are repeated with period n, and the energy is measured with energy_density(ψ, terms; n).

Start with dτ = alpha · (E − target); each trial applies a second-order imaginary-time step trotter_mpos(layers, dτ; evolution=:imaginary) truncated to χ. A trial that reduces |E − target| is accepted and the next dτ is predicted from the measured slope (growth clamped to a factor 2). On rejection, the trial restarts from the last accepted state and dτ is halved. ψ always holds the last accepted state. Each term is shifted by a constant before exponentiation, which changes nothing after normalization but keeps the gates bounded.

Returns (converged, residual, steps). The residual is E − target for the state left in ψ, and steps counts the trials. orth_tol controls orthonormalization during each trial as in truncate!, and tol controls the energy residual.

InfiniteTEBD.evolve! — Method
evolve!(ψ, mpos::AbstractVector{<:iMPO}, steps; maxdim=MAXDIM, cutoff=SVDTOL, truncerr=0.0, renormalize=true, merge=true, return_stats=false, structured=true, observe=nothing, every=1, orth_tol=nothing)

Apply the MPO sequence mpos (one Trotter step, e.g. from trotter_mpos) steps times with apply!, truncating after every MPO. Intermediate truncated states are not regauged (the next application does that); the returned state is canonical and normalized. Each application is transactional, so if one throws (e.g. MPOAnnihilationError), ψ holds the state after the last successful application.

orth_tol is the orthonormalization tolerance of truncate! and applies to each MPO update, observed snapshot, and half-step compression.

Half-step merging: with merge=true and steps > 1, the last MPO of a step and the first MPO of the next step (for :second, U_A(dt/2) U_A(dt/2)) are multiplied and compressed once with compress_mpo. The merged MPO is used at every interior step boundary if its bond dimensions do not exceed those of the two factors (exact for commuting layer MPOs, giving U_A(dt)); otherwise the two are applied separately. Merging removes one MPO application and one truncation per step. Because of it, steps calls of evolve!(ψ, mpos, 1) are not the same integrator as one call with steps: use observe to sample a trajectory.

Observation: observe(φ, k, stats) is called with k = 0 (the input state as given, stats = nothing), after every every complete Trotter steps, and after the last step (also when steps is not a multiple of every). φ is the state at time k·dt returned by the corresponding prefix evolution with the same options. This also holds at a merged boundary, where the pending half step is applied to a snapshot with the final-application settings; the main trajectory, its truncations and the returned ψ are the same as without observe. For 0 < k < steps, φ is a private snapshot the observer may keep; at k = 0 and k = steps it is ψ itself — copy it (deepcopy) to keep it. The observer must not modify φ. stats aggregates the main-line applications since the previous sample. When half steps are merged, an intermediate interval also counts the application that completed the snapshot. At an unmerged boundary, the ordinary ending application is counted once. With return_stats=:summary, the observer receives scalar totals. With false or true, the observer also receives updates for the latest interval.

Returns ψ, or (ψ, stats) with return_stats=:summary or true. The latter also retains updates (the stats of each apply!). The full-run statistics cover only the main trajectory and include sum_discarded_weight, max_discarded_weight, mean_discarded_weight, max_kept_dim, num_bond_updates, num_saturated (requests exceeding maxdim), num_at_cap (dimensions retained at maxdim), num_target_unmet and num_structured, the number of applications that used the structured update. structured=true allows it (see apply!).

Example:

X = [0 1; 1 0]; P = [1 0; 0 0]
layers = [[(kron(P, X, P), 2, 4)], [(kron(P, X, P), 1, 3)]]
U = trotter_mpos(layers, 0.05; n=2)
psi = product_iMPS(ComplexF64, [[1, 0], [1, 0]])
evolve!(psi, U, 20; maxdim=16)

evolve!(ψ, gates, steps; maxdim=MAXDIM, mindim=1, truncerr=0.0, svd_min=SVDTOL, renormalize=true, gauge=nothing, return_stats=false, observe=nothing, every=1)

Each element of gates must be a tuple (G, i, j). A matrix acts on the full periodic interval i:j. A prepared EndpointGate acts at its two endpoints. A ControlledGate acts on a three-site interval.

  • gates Iterable of (G, i, j) tuples, with matrices or prepared gates.

InfiniteTEBD.layer_mpo — Method
layer_mpo(layer, n; cutoff=1e-14, check=true, d=nothing, structured=true)

Build the exact infinite MPO of one commuting layer of local gates, repeated with period n.

layer is a list of (G, i, j) tuples, as in a layer of trotter_gates: a dense gate G (in the kron convention, leftmost site = leftmost factor) on the contiguous sites i..j.

Support convention:

  • (i, j) with i ≤ j are chain sites i, i+1, …, j, and site k lives on unit-cell site mod1(k, n). A support may be longer than the cell: in a two-site cell, the three-site term centred on site 1 is (2, 4) (sites 2, 1, 2 of the cell) and the one centred on site 2 is (1, 3). In general a term of span L centred on c is (c - (L-1)÷2, c + L÷2); any shift by a multiple of n names the same term.
  • j < i is the legacy wraparound of trotter_gates and means j + n.
  • The gate size must equal d^L with L = j - i + 1 (checked).

Precondition (the supported case):

  • Gates may overlap, including a gate with its own translates by n, but only on sites where they commute. check=true verifies this with check_commuting and throws otherwise.
  • Each bond of the cell is crossed by at most one gate (counting translates). This also bounds the span by n + 1. A violation throws an ArgumentError.

Method: each gate is split by an operator Schmidt decomposition (an SVD across each internal bond, dropping singular values below cutoff times the largest on that cut). Where gate pieces share a site, their single-site operators are multiplied in layer order (the first listed gate acts first). Bonds that no gate crosses get bond dimension 1. Since every bond is crossed by one gate, the MPO bond dimension equals the operator Schmidt rank of that gate across that bond, and the MPO equals the product of all gates exactly (up to the dropped singular values).

Returns an iMPO with cell length n.

Structure: with structured=true, a layer of one three-site gate on a two-site cell (local dimension 2) that is diagonal in its two outer sites — PXP-type gates, with or without a folded blockade projector, real or imaginary time — is recorded as a ControlledCenter in the returned MPO. apply! then uses an equivalent sector-resolved update (much faster for PXP); all other layers, and structured=false, use the generic update.

Example (PXP: each gate flips the centre only if both neighbours are empty, so the operator Schmidt rank is 2 on every bond):

X = [0 1; 1 0]; P = [1 0; 0 0]
U = exp(-0.1im * kron(P, X, P))
W = layer_mpo([(U, 2, 4)], 2)   # gates centred on the odd sites of a 2-site cell
bonddims(W)                     # [2, 2]

InfiniteTEBD.log_per_site_fidelity — Method
log_per_site_fidelity(a, b; period=nothing, tol=nothing, maxiter=nothing,
                     strict=true, self_overlaps=(nothing, nothing))

Log of the normalized overlap amplitude per physical site of two dense iMPS or two vectors of stored local tensors. Neither input is mutated or canonicalized. The default tol is 1e-14 or ten machine epsilons for lower-precision tensors. A positive log fidelity consistent with roundoff is rounded to zero. A larger violation indicates insufficient transfer accuracy or inconsistent supplied overlaps.

Return a smooth spectrum-derived estimate of the intrinsic bond dimension associated with Schmidt values λ.

The score is based on the Rényi effective rank of order q on the normalized weights p_i = abs2(λ_i) / sum(abs2, λ), optionally amplified by the total tail weight 1 - p_1 (where p_1 is the largest normalized weight). scarfinder_step!(ψ, h, dt, χ; trotter=nothing, layers=nothing, …)

One ScarFinder iteration: evolve!(ψ, U, nstep; maxdim, cutoff), then project!(ψ, χ; …). Returns the named tuple of project!.

U is anything evolve! accepts: a sequence of (G, i, j) gates (matrices, EndpointGates, ControlledGates), a vector of layer MPOs from trotter_mpos, or a single local gate G, applied at every translation of the cell. A local density h in place of terms gives the terms (h, i, i + span − 1) for every site of the cell. The form (h, dt) evolves with exp(−i dt h) at every translation (trotter=nothing) or with trotter_gates(layers, dt; trotter), and corrects the energy with h.

The term period n defaults to the cell length of the first MPO, or ψ.n. Projection arguments are checked before evolution. Gate sequences are validated as each gate is applied, so a later error can leave earlier updates in place. nstep = 1 warns because one iteration should contain several microscopic steps.

After a nonempty built-in MPO evolution, the projection can reuse the normalized Schmidt basis when both the cut and the dominant transfer fixed point are well separated. A cut still restores the gauge on the retained support. The tensor gauge and roundoff can differ from separate calls to evolve! and project!. orth_tol controls orthonormalization during projection and built-in MPO evolution. Local gate evolution uses its own canonicalization.

InfiniteTEBD.schmidt_values — Method
schmidt_values(ψ, i)

Return the Schmidt spectrum on bond i as a freshly-allocated Vector{Float64}, independent of whether ψ is dense or symmetric.

For dense iMPS, this is a copy of ψ.λ[i] with eltype Float64. For the symmetric backend (loaded via using TensorKit), the extension's specialisation flattens the per-sector diagonal blocks of ψ.λ[i]::DiagonalTensorMap into a single descending-sorted Vector{Float64}.

The result is always a fresh array — mutating it does not affect the state.

InfiniteTEBD.translate — Method
translate(ψ, k)

The state translated by k sites along the chain, as a new iMPS with independent arrays: out.Γ[i] = ψ.Γ[mod1(i - k, n)] and out.λ[i] = ψ.λ[mod1(i - k, n)] (each stored tensor B = Γλ moves with the Schmidt spectrum of its right bond), so the canonical form is kept. The content of site j of ψ ends up on site j + k; k may be negative, and translate(ψ, n) == ψ for a cell of n sites.

For the staggered PXP chain, a one-site translation maps the Hamiltonian with detunings (μ+δ, μ−δ) to the one with (μ−δ, μ+δ): at δ ≠ 0 it is not a symmetry of a fixed grid point.

InfiniteTEBD.trotter_gates — Method
trotter_gates(layers, dt; trotter=:second, evolution=:real, steps=1)

Materialize steps Trotter macro-steps from a Hamiltonian split into commuting layers, as used by evolve!(ψ, layers, dt, steps). For multiple layers the schedule merges adjacent substeps of the same layer across step boundaries. For one layer it keeps the individual steps and their intermediate truncations.

Each element of layers is a collection of local Hamiltonian terms (h, i, j). Terms inside a single layer are assumed to commute, so their dense gates can be applied sequentially in the supplied order. The package does not check commutation automatically.

Parameters:

  • layers Hamiltonian split into commuting layers. Each local term reuses the tuple shape (h, i, j) with dense operator h supported on the unit-cell region i:j.
  • dt Microscopic time step.

Keyword arguments:

  • trotter=:second Trotter scheme. Use :second for Strang splitting, :fourth for Suzuki's recursive fourth-order composition, or :fourth_opt for the two-layer optimized real-time formula of Barthel and Zhang.
  • evolution=:real Use :real to build gates exp(-1im * c * dt * h) or :imaginary to build second-order imaginary-time gates exp(-c * dt * h).
  • steps=1 Number of macro-steps to generate. Zero returns an empty gate list.

Returns:

  • A vector of local gates (G, i, j) for the full requested interval. Diagonal terms yield Diagonal gates. Apply the vector once with evolve!(ψ, gates, 1). Entries can share a matrix; copy it before editing an individual gate.

Notes:

  • trotter = :fourth_opt requires exactly two layers.
  • Higher-order Trotter schemes currently reject evolution = :imaginary because their negative substeps are only supported for real-time evolution.

Example:

X = [0 1; 1 0]
H = kron(X, X)
layers = [[(H, 1, 2)], [(H, 2, 1)]]
gates = trotter_gates(layers, 0.1; trotter=:fourth_opt)

InfiniteTEBD.trotter_mpos — Method
trotter_mpos(layers, dt; trotter=:second, evolution=:real, n, cutoff=1e-14, check=true, gate_map=identity)

The sequence of layer MPOs for one Trotter step of length dt.

layers has the same shape as for trotter_gates: each layer is a list of local terms (h, i, j) whose overlapping terms commute. The supports follow the convention of layer_mpo (i ≤ j may span more than the cell n). The stage schedule and time prefactors are those of trotter_gates (_trotter_stage_schedule, _trotter_time_prefactor), so :second gives [U_1(dt/2), U_2(dt/2), …, U_m(dt), …, U_1(dt/2)] and :fourth/:fourth_opt their real-time compositions. Each stage becomes layer_mpo([(exp(c·h), i, j) …], n) with c = -i·coeff·dt for evolution=:real and c = -coeff·dt for evolution=:imaginary.

With check=true, each layer's terms are checked with check_commuting once (commuting terms give commuting gates).

gate_map is applied to every exponentiated gate before it is split into an MPO, e.g. gate_map = G -> P3 * G folds a blockade projector P3 into each gate. The mapped gates must still commute where they overlap (with check=true they are checked again).

Returns a Vector{iMPO}; apply it with evolve!(ψ, mpos, steps), which merges the half steps at step boundaries.

Example:

X = [0 1; 1 0]; P = [1 0; 0 0]; nn = [0 0; 0 1]; I2 = [1 0; 0 1]
h(c) = kron(P, X, P) + c * kron(I2, nn, I2)
layers = [[(h(1.2), 2, 4)], [(h(0.6), 1, 3)]]   # A = site 1, B = site 2
U = trotter_mpos(layers, 0.05; n=2)             # [U_A(dt/2), U_B(dt), U_A(dt/2)]

InfiniteTEBD.truncate! — Method
truncate!(ψ::iMPS, χ; cutoff=SVDTOL, truncerr=0.0, renormalize=true,
          return_stats=false, orth_tol=nothing)

Truncate every bond of ψ to at most χ Schmidt values, treating all bonds alike.

Procedure: bring ψ to exact canonical form; then each bond keeps its own χ largest Schmidt values (fewer if truncerr > 0 allows it, or if values fall below cutoff); the canonical gauge is then restored. Because no bond is singled out, a state that is invariant under a translation of the cell stays invariant (up to roundoff) — tiling a two-site state onto four sites and truncating gives the tiled truncated two-site state.

The state is updated only after truncation and canonicalization succeed.

orth_tol sets the tolerance on the left and right orthonormalization residuals (Frobenius norm of the change in the normalized seam factor per sweep). With nothing, the sweeps target 1e-13 and may accept a residual up to 1e-10 after stalling or reaching the sweep cap. With a finite positive tolerance, failure to meet it within the sweep budget raises CanonicalFormError. This tolerance is separate from the Schmidt cutoff.

Returns ψ, or (ψ, stats) with return_stats=true; stats has fields bond_stats, max_discarded_weight, kept_dims and num_saturated.

Example:

psi = rand_iMPS(ComplexF64, 2, 2, 8)
truncate!(psi, 2)
length.(psi.λ)      # [2, 2]

InfiniteTEBD.uniform_layers — Method
uniform_layers(ψ, h; span=operator_span(ψ, h))

Build commuting layers for every translation of a local density h on the periodic unit cell. Gates in one layer have disjoint supports. If the cell length is divisible by span, this uses exactly span layers. For other cell lengths it uses the minimum number of layers with disjoint supports. Supply custom layers to trotter_gates for overlapping terms known to commute.
